# مصاريفي الشهرية — تطبيق ويب

تطبيق عربي (RTL) لتتبّع المصاريف الشهرية، يعمل في المتصفح بالكامل بدون إنترنت وبدون أي مكتبات خارجية.

## التشغيل

من داخل مجلد المشروع:

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File expenses-app/serve.ps1 -Port 5173
```

ثم افتح `http://localhost:5173`.

> يمكن أيضاً فتح `index.html` مباشرة، لكن تشغيله عبر خادم محلي أفضل لضمان عمل الحفظ في `localStorage`.

## التشغيل والتثبيت على الهاتف

### الطريقة الأولى — نفس شبكة الواي فاي (بدون إنترنت)

1. شغّل الخادم على الكمبيوتر بصلاحيات **مسؤول**:

   ```
   powershell -NoProfile -ExecutionPolicy Bypass -File expenses-app/serve.ps1 -Public
   ```

   سيطبع عنواناً مثل `http://192.168.1.20:5173/`.
2. اسمح للمنفذ في جدار الحماية مرة واحدة (كمسؤول):

   ```
   netsh advfirewall firewall add rule name="Masarifi 5173" dir=in action=allow protocol=TCP localport=5173
   ```
3. افتح العنوان في متصفح الهاتف (الكمبيوتر يجب أن يبقى شغالاً).

### الطريقة الثانية — تثبيت كامل كتطبيق (مستحسن)

ارفع محتويات مجلد `expenses-app` على أي استضافة **HTTPS** مجانية (GitHub Pages أو Netlify Drop)،
ثم افتح الرابط في الهاتف:

- **أندرويد / Chrome:** قائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»
- **آيفون / Safari:** زر المشاركة ← «إضافة إلى الشاشة الرئيسية»

يعمل بعدها كتطبيق مستقل بملء الشاشة وبدون إنترنت (عبر Service Worker)، وتبقى البيانات محفوظة في الجهاز.

> التثبيت الكامل يتطلب HTTPS. عبر `http://192.168.x.x` يعمل التطبيق لكن دون تثبيت أو عمل بدون إنترنت.


## نسخة أندرويد (APK)

يوجد في `../android` مشروع أندرويد أصلي يغلّف التطبيق:

- ملفات الويب **مضمّنة داخل الـ APK** (`app/src/main/assets`) — لا يحتاج إنترنت ولا خادماً
- تُقدَّم عبر أصل آمن وهمي `https://masarifi.local/` ليعمل `localStorage` بشكل موثوق
- بلا شريط عنوان، بلا صلاحية إنترنت، وصلاحية الاهتزاز فقط
- زر الرجوع في الجهاز يغلق النوافذ ويرجع للشاشة الرئيسية قبل أن يخرج من التطبيق

### إعادة البناء بعد أي تعديل على التطبيق

```
node -e "const fs=require('fs');let h=fs.readFileSync('expenses-app/index.html','utf8');h=h.replace(/<link rel=\"manifest\"[^>]*>\n?/,'').replace(/<script>[\s\S]*?serviceWorker[\s\S]*?<\/script>\n?/,'');fs.writeFileSync('android/app/src/main/assets/index.html',h)"
```

ثم انسخ `styles.css` و`app.js` و`sounds.js` إلى `android/app/src/main/assets/` وشغّل:

```
gradle assembleDebug
```

مع ضبط `JAVA_HOME` على `C:\Program Files\Android\openjdk\jdk-21.0.8`.
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الشاشات الثلاث والنوافذ المنبثقة |
| `styles.css` | الهوية البصرية كاملة (الكحلي/الذهبي/الكريمي) ومسافات الأمان |
| `app.js` | الحالة، التخزين، التقويم، التصنيفات، الضبط |
| `sounds.js` | توليد الأصوات برمجياً عبر Web Audio API |
| `serve.ps1` | خادم ملفات محلي بسيط (`-Public` للوصول من الهاتف) |
| `manifest.json` | بيانات التثبيت كتطبيق (PWA) |
| `sw.js` | Service Worker — التشغيل بدون إنترنت |
| `icon.svg` / `icon-maskable.svg` | أيقونة التطبيق على الشاشة الرئيسية |

## الشاشات

1. **الرئيسية** — تنقّل بين الشهور، **المبلغ الإجمالي** و**المدخرات** (مخفيان بالنجوم ✦)، خانة المجموع، قائمة المصاريف، زر إضافة، وزر **الضبط** الصغير في الأسفل.
   - الضغط على خانة المبلغ الإجمالي أو المدخرات يفتح نافذة إدخال الرقم.
   - زر العين 👁 يُظهر/يُخفي المبالغ (لا يُحفظ — يعود للإخفاء عند إعادة الفتح).
   - **خانة المجموع** تعرض الفارق: `المبلغ الإجمالي − (المصاريف + المدخرات)`، وتتحول للأحمر عند التجاوز.
     قبل تحديد المبلغ الإجمالي تعرض مجموع المصاريف كما هو (العنوان يتبدّل بين "المجموع" و"المتبقي").
   - القيمتان تُحفظان لكل شهر على حدة.
2. **تفاصيل المصروف** — التاريخ (تقويم عربي مخصص)، الملاحظة، المبلغ، 15 تصنيفاً، 5 ألوان، حفظ/رجوع/حذف.
   اللون المختار يظهر في القائمة: يلوّن دائرة الأيقونة والشريط الجانبي للبطاقة.
3. **الضبط** — يُفتح من زر ⚙️ الصغير أسفل الشاشة الرئيسية:
   - **مفتاح تشغيل/إيقاف الصوت** (محفوظ تلقائياً)
   - مستوى الصوت 0–100%
   - العملة الافتراضية (ر.ع افتراضياً)
   - تصدير/استيراد JSON
   - مسح كل البيانات (بتأكيد مزدوج)

## الأصوات

مولّدة بالكامل عبر Web Audio API — لا توجد ملفات صوتية:

| الحدث | الوصف |
|---|---|
| `click` | نقرة قصيرة عند أي زر |
| `toggle` | نقرة خفيفة عند اختيار أيقونة/لون |
| `navigate` | انزلاق خفيف عند تغيير الشهر أو الشاشة |
| `save` | نغمة صاعدة عند الحفظ |
| `delete` | نغمة هابطة عند الحذف |
| `error` | تنبيه عند إدخال غير صالح |

كل الأصوات تمر عبر `Sound.play()` التي تتحقق من الإعداد قبل التشغيل، ويبدأ `AudioContext` عند أول تفاعل من المستخدم.
يُضاف اهتزاز خفيف عبر `navigator.vibrate` على الأجهزة الداعمة.

## البيانات

تُحفظ في `localStorage` تحت المفاتيح:

- `mx_expenses` — قائمة المصاريف
- `mx_budgets` — المبلغ الإجمالي والمدخرات لكل شهر (`{"2026-07":{"budget":500,"savings":50}}`)
- `mx_settings` — الصوت والعملة ومستوى الصوت
- `mx_seeded` — علامة إدخال البيانات التجريبية (مصروفا بترول في يوليو 2026) عند أول تشغيل فقط

## ملاحظات التصميم

- مسافة أمان علوية وسفلية عبر `env(safe-area-inset-*)` حتى لا يختفي المحتوى خلف شريط حالة الجوال أو شريط الإيماءات.
- يملأ عرض الشاشة بالكامل، ومتجاوب حتى 360px.
- دعم `prefers-reduced-motion` و`aria-label` لكل زر.
